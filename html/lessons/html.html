HTML Basics

Role of HTML: HTML represents the content and structure of a web page.

HTML elements: Elements are the building blocks of an HTML document. Most elements have an opening tag and a closing tag.

<elementName>Content goes here</elementName>

Void elements: Void elements cannot have content and only have a start tag. The slash is optional.

<img>
<meta>
<img/>

Attributes: Attributes provide additional information or behavior for an element. Boolean attributes are true when present and false when absent.

<element attribute="value"></element>

<input disabled readonly required>

Comments: Comments leave notes in the source without displaying them on the page.

<!-- This is an HTML comment. -->

Common HTML Elements

Heading elements: HTML has six heading levels. h1 is the most important and h6 is the least important.

<h1>Most important heading</h1>
<h2>Second-level heading</h2>
<h3>Third-level heading</h3>
<h4>Fourth-level heading</h4>
<h5>Fifth-level heading</h5>
<h6>Least important heading</h6>

Paragraphs and images: Use p for paragraphs and img with descriptive src and alt attributes for images.

<p>This is a paragraph element.</p>

<img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/lasagna.jpg"
     alt="A slice of lasagna on a plate.">

Containers: The body, section, and div elements group page content. The section element has semantic meaning; div is a generic container.

<section>
    <h2>About Me</h2>
    <p>Hi, I am Jane Doe and I am a web developer.</p>
</section>

<div>
    <h1>I am a heading</h1>
    <p>I am a paragraph</p>
</div>

Links and lists: Use a with href for links, ul for bulleted lists, and ol for ordered lists.

<a href="https://cdn.freecodecamp.org/curriculum/cat-photo-app/running-cats.jpg">Cute cats</a>

<ul>
    <li>catnip</li>
    <li>laser pointers</li>
    <li>lasagna</li>
</ul>

<ol>
    <li>flea treatment</li>
    <li>thunder</li>
    <li>other cats</li>
</ol>

Text and figures: em adds emphasis, strong marks strong importance, and figure with figcaption groups media with its caption.

<p>Cats <em>love</em> lasagna.</p>

<figure>
    <img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg"
         alt="Two tabby kittens sleeping together on a couch.">
    <figcaption>Cats <strong>hate</strong> other cats.</figcaption>
</figure>

Page controls: main identifies the primary content, footer identifies the bottom content, and button creates a clickable control.

<button>Click me</button>

<footer>
    <p>No Copyright - <a href="https://www.freecodecamp.org">freeCodeCamp.org</a></p>
</footer>

Identifiers and Grouping

IDs: An ID uniquely identifies one element in a document. ID names cannot contain spaces.

<h1 id="title">Movie Review Page</h1>
<div id="red-box"></div>

Classes: Classes group elements for styling and behavior. A class can be reused, and an element can have multiple classes.

<div class="box"></div>
<div class="box red-box"></div>
<div class="box blue-box"></div>

Special Characters and Linking

HTML entities: Character references represent reserved characters in HTML, such as the ampersand and less-than symbols.

<p>This is an &lt;img /&gt; element</p>

Link element: Use link to connect external resources such as stylesheets and site icons. The rel attribute describes the relationship and href gives the resource URL.

<link rel="stylesheet" href="./styles.css" />

Script element: Use script to embed or link executable JavaScript. Linking an external file is generally preferred.

<script src="path-to-javascript-file.js"></script>

Boilerplate and Encoding

HTML boilerplate provides the basic structure and essential metadata for a document. DOCTYPE identifies the HTML version, html is the root element, and head contains metadata.

<!DOCTYPE html>
<html lang="en">
    <head>
        <meta charset="utf-8" />
        <title>freeCodeCamp</title>
        <link rel="stylesheet" href="./styles.css" />
    </head>
    <body>
        <!-- Headings, paragraphs, images, etc. go inside here -->
    </body>
</html>

UTF-8: UTF-8 is a widely used character encoding. Set it with the charset attribute on a meta element.

SEO and Social Sharing

SEO: Search Engine Optimization helps pages become more visible and rank higher in search engines.

Description metadata: A description summarizes the page for search engines.

<meta name="description"
      content="Discover expert tips and techniques for gardening in small spaces." />

Open Graph tags: Open Graph properties control how shared content appears on services such as Facebook and LinkedIn.

<meta property="og:title" content="freeCodeCamp.org" />
<meta property="og:type" content="website" />
<meta property="og:image" content="https://cdn.freecodecamp.org/platform/universal/fcc_meta_1920X1080-indigo.png" />
<meta property="og:url" content="https://www.freecodecamp.org" />

Media Elements and Optimization

Replaced elements: An element such as iframe gets its content from an external resource.

<iframe src="https://www.example.com" title="Example Site"></iframe>

<iframe src="video-url" width="560" height="315" allowfullscreen></iframe>

Media optimization: Consider the size, format, and compression of media. WEBP and AVIF are often more efficient than PNG and JPG. Check image licenses before publishing.

SVG: Scalable Vector Graphics use paths and equations, so they can scale without losing quality.

Multimedia Integration

Audio and video: These elements support media files such as MP3, WAV, OGG, MP4, and WEBM. The controls attribute displays playback controls; autoplay, loop, and muted are boolean attributes.

<audio src="CrystalizeThatInnerChild.mp3" controls></audio>

<video src="video.mp4" loop controls muted poster="poster.jpg" width="620"></video>

Source elements: Multiple sources let the browser choose the first format it supports.

<audio controls>
    <source src="audio.ogg" type="audio/ogg" />
    <source src="audio.wav" type="audio/wav" />
    <source src="audio.mp3" type="audio/mpeg" />
</audio>

Target Attribute Types

The target attribute tells the browser where to open an anchor URL. _self is the current context, _blank opens a new context, _parent opens in the parent frame, and _top opens in the top-level context.

<a href="https://freecodecamp.org" target="_self">Visit freeCodeCamp</a>
<a href="https://freecodecamp.org" target="_blank">Visit freeCodeCamp</a>
<a href="https://freecodecamp.org" target="_parent">Visit freeCodeCamp</a>
<a href="https://freecodecamp.org" target="_top">Visit freeCodeCamp</a>

Absolute vs. Relative Paths

A path identifies a file or directory. A slash separates names, a single dot means the current directory, and two dots mean the parent directory.

public/index.html
./favicon.ico
../src/index.css

Absolute path: A complete route from the root directory. An absolute URL also includes a protocol and domain.

<a href="https://design-style-guide.freecodecamp.org/img/fcc_secondary_small.svg">
    View the freeCodeCamp logo
</a>

Relative path: A resource location relative to the current document.

Link States

:link: The default state for a link that has not been visited.

:visited: The state for a link the user has already visited.

:hover: The state while the pointer is over a link.

:focus: The state when a link receives keyboard or programmatic focus.

:active: The state while a link is being activated, usually during a click.
